# No Distractions

A minimal, neon-themed focus page designed to remind me to get back to work whenever I try to visit a distracting website.

Built with HTML, CSS, and JavaScript, this page acts as a personal focus screen when paired with the **BlockSite browser extension**.

##  Features

- **Neon UI:** A dark background, glowing cyan text, and a futuristic glass-like panel.
- **Focus Reminders:** A personal message to stay focused and finish the work that matters.
- **Scary Popup:** An animated red popup displaying *"👀 I SEE YOU"* to catch my attention.
- **Temporary Dismissal:** Clicking OK closes the popup, which automatically reappears after 20 seconds.
- **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript. No frameworks or external libraries required.

## Purpose

This project was created to make procrastination a little harder.

Instead of simply blocking distracting websites, I redirect them to a custom page that reminds me why I should stay focused. The goal is to turn an attempted distraction into a quick reality check.

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Neon styling, glowing effects, layout, and shake animation
- **JavaScript** — Popup dismissal and automatic reappearance

## Setup
Configure the extension to redirect blocked websites to the page's URL, if supported by your setup.

For local use, you may need to host the page locally or publish it using a static hosting service such as GitHub Pages, depending on the extension's redirect options.
